# 의외성 추천 후속 아이디어 메모

작성: 2026-11-03 · 상태: 아이디어 모음(구현 안 함)

지금 모델(SERP-v1)은 그대로 둬요. 아래는 나중에 공유 문서에 옮길 후보만 모아 둔 거예요. 위에 있을수록 먼저 검토할 만한 것이에요.

---

## 1. 콜드 스타트: 개인 기록 없이 기준점 세우기

지금은 "동대문구 출발 집단의 관성(거리순·인기순·과거 유입순 상위)"을 개인 기록 대신 기준점으로 써요. 이걸 바꾸거나 보강하는 방법들이에요.

### 1-1. 액티브 러닝으로 개인 기준 모형 만들기 (우선)

- 앱을 처음 켤 때 상권·가게 카드 5장 정도를 보여 줘요.
- 카드마다 두 가지를 물어요. 하나는 "가 봤어요 / 알아요 / 처음 봐요"이고, 다른 하나는 "가고 싶어요"예요.
- "가 봤어요·알아요"라고 답한 곳과 그와 비슷한 곳을 그 사람의 기준 모형(관성)으로 삼아요. Murakami·Ge 지표에서 말하는 primitive model이에요.
- 추천은 "기준 모형 밖 ∩ 가고 싶어요와 비슷한 곳"에서 해요.
- 카드는 성격이 많이 다른 곳(전통시장 / 카페거리 / 노포 / 대형 역세권)을 섞어 골라요. 그래야 응답 몇 개로 취향이 갈려요.
- 응답 구조가 Kotkov 2018 설문(새로움·의외성·관련성)과 같아서, 쌓이면 검증 라벨로 그대로 쓸 수 있어요.

### 1-2. 맥락(날씨·시간대) 기반 추천 (우선)

- 날씨, 시간대, 요일 같은 지금의 상황을 기준점에 더해요.
- 예를 들어 비 오는 날에는 실내형 상권(지하상가, 전통시장 아케이드, 복합몰)에 가점을 줘요. 저녁에는 여가문화 목적의 가중을 올려요.
- 이미 가진 것: 08·14·19시 도달률(PATH-v0). Chowdhury 등(2020)은 출발 시각과 목적지 선택이 강하게 엮여 있다고 보고했어요.
- 필요한 것: 날씨 데이터(기상청 예보 API 등, 이용 조건 확인 필요)와 상권별 실내·실외 구분 태그.
- 맥락별로 관성도 따로 잡을 수 있어요. "비 오는 저녁에 보통 가는 곳"과 다른 곳을 추천하는 식이에요.

### 1-3. 나머지 (참고)

| 방법 | 한 줄 | 판단 |
|---|---|---|
| 인구통계 집단 기준점 | 성별·연령 집단의 평균 취향을 기준으로 삼아요 | 보류. 찾은 자료(Erasmus 학위논문 2019)는 인구통계를 넣으면 새로움이 줄었다고 해요 |
| 지식 그래프·온톨로지 | 상권-업종-점포 관계를 타고 "연결은 있지만 분야가 다른 곳"을 찾아요 | 참고. Kuznetsov(2023) 온톨로지 기반 콜드 스타트 세렌디피티 논문이 있지만 본문은 미확인이에요 |
| 밴딧(탐색) | 추천 일부를 새 후보에 할당해 반응을 보며 배워요 | 서비스를 실제로 운영한 뒤에 해요. 탐색만으로는 관련성이 보장되지 않아요 |

## 2. 롱테일 × 관련성: 덜 알려졌는데 갈 만한 곳

### 문제

v1 상위 10곳이 사실상 인기 상권이에요. 식사 상위 10곳의 목적 매출 인기 백분위 중앙값은 0.87이고, 인기 하위 50%인 곳은 0곳이에요. R이 "구조로 예측한 매출"이라 인기와 같이 움직이기 때문이에요.

"인기 하위 50% ∩ R ≥ 0.6" 칸은 작아요. 식사 36곳, 카페 49곳, 쇼핑 42곳, 여가문화 29곳이에요(786곳 중, 2025년 4분기).

예시:
- 식사: 홍릉시장, 서울숲카페거리, 간데메공원
- 카페: 화양사거리, 자양4동주민센터
- 쇼핑: 평화시장, 마장축산물시장, 능동로골목시장

### 후보 방법

- **R을 규모가 아니라 질로 재기**: 점포당 매출, 업종 비중, 영업 지속기간처럼 큰 상권이 저절로 이기지 않는 값을 써요.
- **인기 구간별 자리 나누기**: 추천 10곳 중 몇 곳은 꼬리 칸에서 고르게 해요. Forster 등(2025)의 인기 보정과 같은 생각이에요. 지금 `band_picks`(이동시간 구간별 3곳)와 같은 구조예요.
- 어느 쪽이든 꼬리 칸의 R은 예측값이에요. 설문 "가 보고 싶나요" 점수로 관련성이 무너지지 않는지 확인해야 해요.

## 4. 상권 단위 다시 정하기

- 지금은 서울시 공식 상권 폴리곤 1,650개 중 접근률 25% 이상인 786개가 후보예요(`docs/commercial_area_definition.md`, editpanda-dev 저장소 `codex/geonwoo/meal-shopping-v1`).
- 관광특구는 폴리곤이 너무 넓어요(중앙값 대각선 1.7km, 최대 4.1km). "이태원 관광특구"만으로는 어디로 가야 할지 알 수 없어요.
- 글로벌캠(모현)에서는 공식 상권이 없어서 점포 좌표를 DBSCAN으로 묶어 상권을 새로 만들었어요(반경 100m, 1.5km 넘게 길면 60m로 다시 나눔, 30점포 이상). 같은 방법으로 서울의 넓은 상권을 쪼개는 걸 검토할 수 있어요.
