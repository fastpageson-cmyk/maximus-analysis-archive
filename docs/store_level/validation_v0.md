# 점포 단위 의외성 v0 검증

기준일: 2026-11-03 · 브랜치 `gunwoo/store-level`
설계: `docs/store_level/recommendation_options.md` 4.2·6.6절 · 스크립트 `scripts/store_level/validate_store_serendipity_v0.py` · 숫자 원본 `data/processed/store_level/validation_summary_v0.json`

## 먼저 알아 둘 것: v0는 공공데이터판이다
네이버 키워드 집계 요청(`getVisitorReviewStats`)은 캡차 토큰 없이 보내면 첫 요청부터 429가 온다(2026-11-03, 헤더 형식을 맞추고 간격을 20초 이상으로 늘려도 같음). 캡차 토큰을 재사용하는 수집은 하지 않았다. 장소 검색(instant-search)은 토큰 없이 된다.
그래서 모든 점포가 `review_evidence=low`다. 리뷰 항(`fit`, `u_content`, `u_local`)은 0.5다. 점수는 영업연수·착한가격·희소도·노포/10년+로만 정해진다. 아래 1·2번은 데이터가 없어서 하지 못했다.

## 1. 테마 안정성
**데이터 없음.** 키워드 집계가 생기면 가게별 키워드 수를 다항분포로 1,000번 다시 뽑아 상위 테마가 유지되는 비율을 n 구간(20~49, 50~99, 100+)별로 잰다. 기준은 n ≥ 20에서 0.8이다.

## 2. 구성 타당도
**데이터 없음.** 가성비·양 테마와 착한가격 지정의 AUC, 분식·국수 업종의 혼자 테마 평균, 감성 테마와 영업연수의 스피어만 상관은 키워드 집계가 있어야 계산할 수 있다.

## 3. 편향
| 구분 | review_evidence=low 비율 |
|---|---:|
| 노포 / 비노포 | 1.0 / 1.0 |
| 골목상권 / 발달상권 / 전통시장 / 관광특구 | 1.0 / 1.0 / 1.0 / 1.0 |

모두 low라 차이가 없다. 경고 조건(노포 쪽이 10%p 이상 높음)에는 걸리지 않는다. 리뷰 데이터가 생기면 다시 재야 한다.

## 4. 기여 분석 (목적별 추천 목록)
| 목적 | 추천 수 | 리뷰 있음/없음 자카드 | 관성 상권 겹침률 | ILD(소분류) |
|---|---:|---:|---:|---:|
| 식사 | 30 | 1.0 | 0.0 | 0.952 |
| 카페 | 21 | 1.0 | 0.0 | 0.652 |
| 공부 | 25 | 1.0 | 0.0 | 0.847 |
| 쇼핑 | 30 | 1.0 | 0.0 | 0.977 |
| 여가문화 | 24 | 1.0 | 0.0 | 0.935 |

- 리뷰 특성이 없어서 '리뷰 있음'판과 '리뷰 없음'판(안 B)이 같다. 자카드가 1.0인 건 그 때문이다. 테마 커버리지도 잴 수 없다.
- **관성 상권 겹침률 0.** 추천 점포가 모두 관성 Top-K 밖 상권에서 나왔다. 이는 상권 단계(SERP-v0)에서 이미 관성 상권이 아래로 밀린 결과다.
- ILD는 목록 안에서 소분류가 다른 쌍의 비율이다. 카페는 소분류가 '카페·커피숍·전통찻집' 정도라 낮다.
- 출발점은 동대문구다(2026-11-03 팀 결정). 점포는 상권 대표점에서 도보 10분 안만 남긴다. K=10 후보의 제외 비율은 4.3%다(서울캠 기준이었으면 73.5%).
- 카페·공부·여가가 30곳에 못 미치는 건 상권 안에 같은 목적 점포가 적어서 3곳을 못 채우는 상권이 있기 때문이다.

민감도(`store_serendipity_sensitivity_v0.csv`): 가중치를 ±0.1 바꿨을 때 상위 집합 자카드는 0.82~1.0이다. 상권 10곳 × 3곳이 최대 30곳이라 집합이 거의 정해져 있다. K=20일 때는 0.41~0.67이다.

## 5. 매칭 감사
| 표본 | 상태 |
|---|---|
| 인허가 ↔ 상가정보 `match_audit_sample_v0.csv` (50곳) | **Claude 1차 판정**(사람 검수 전): 맞음 47, 애매 3, 틀림 0 → 정밀도 1.0(애매 제외), 보수적 0.94(애매를 틀림으로) |
| 네이버 장소 연결 `naver_match_audit_sample_v0.csv` | 파일 없음: 장소 연결을 1곳만 시험했다 |

- 판정 기준은 "같은 가게인가"다. 인허가 연도가 맞는지(지위승계 뒤 남은 옛 연도)는 판정하지 않았다.
- 애매 3곳: '스시' ↔ '스시코리아'(일반 이름이 포함만 됨), '주' ↔ '주'(한 글자 상호), '뚝도돼지' ↔ '뚝도지기'(이름이 다름, 상호 변경일 수 있음). 세 곳 모두 짧은 이름이 포함 관계로 묶인 경우라, 상호가 3글자 미만이면 포함 규칙을 끄는 방안을 v1에서 검토한다.
- 사람이 `판정` 칸에 `맞음 / 틀림 / 애매`를 적으면 스크립트가 그 값을 먼저 쓴다. 목표는 0.9 이상이고, 1차 판정 기준으로는 넘는다.

## 6. 설문 카드
- `survey_cards_v0.csv`: 30세트 × 20장. 열은 set_id, order, card_id, 상호, 소분류명, area_name, 상권 안 도보, reason. '상권 안 도보'는 대표점에서 점포까지(역·정류장 바로 앞 ≤2분 / 도보 5분 안 / 5~10분)다. 상권 자체는 동대문구 30분 안 후보다.
- `survey_cards_key_v0.csv`: card_id → method(serendipity / near_rep / random_area / inertia_rule), purpose. **응답자에게 보여 주지 않는다.**
- 세트 구성: 의외성 상위 10장 + 기준선 10장. 기준선은 세 종류를 무작위로 섞어 평균 3.3장씩이고, 세트 안 같은 가게는 없다. 순서도 무작위다(seed 42).
  - near_rep: 같은 상권·목적에서 상권 대표점에 가장 가까운 비프랜차이즈 3곳
  - random_area: 같은 상권·목적 안 무작위 비프랜차이즈 3곳
  - inertia_rule: 관성 상권(식사·카페)에서 같은 점수 규칙으로 MMR 3곳
- 카드 덱 크기: 의외성 130, near_rep 140, random_area 140, inertia_rule 125.
- **출처 노출 대응.** 공공 태그(노포·10년+·착한가격·희소 업종)가 있는 카드 비율이 방법마다 다르다. 덱 기준으로 의외성 0.75, inertia_rule 0.76, near_rep 0.23, random_area 0.23이다. 이유 문장을 먼저 보여 주면 응답자가 "태그 있음 = 추천"으로 읽을 수 있다. 그래서 아래 두 가지를 적용한다.
  1. 구글폼에서 **Q1~Q3은 이유 문장 없이** 상호·소분류명·area_name·상권 안 도보만 보여 주고 묻는다. 이유 문장은 Q4 화면에서만 보여 준다.
  2. 키 파일 `survey_cards_key_v0.csv`에 `has_tag` 열을 두었다. 분석 로짓에 공변량으로 넣어 "태그 효과"와 "방법 효과"를 나눈다.

### 구글폼 문항 (카드마다)
카드 한 장 = 화면 2개. 화면 1(이유 문장 없음): Q1~Q3. 화면 2(이유 문장 보여 줌): Q4.

| 문항 | 보기 |
|---|---|
| Q1. 이 가게를 아나요? | 가 봄 / 들어 봄 / 처음 |
| Q2. 평소 갈 곳으로 떠올렸을까요? | 1(전혀) ~ 5(매우) |
| Q3. 동대문구에서 30분 안이면 가 보고 싶나요? | 1 ~ 5 |
| Q4. 가 봤다면 카드에 적힌 특징이 맞았나요? | 예 / 아니오 / 안 가 봄 |

세렌디피티 적중 = Q1 '처음' ∧ Q2 ≤ 2 ∧ Q3 ≥ 4 (설계 문서 4.2절). 응답자 20~30명에게 세트 하나씩 배정한다.
